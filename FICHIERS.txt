⚙️ TECHNOLOGIES UTILISÉES:

Backend:
  - Node.js + Express (API)
  - Supabase (Auth + Base de données)
  - CORS (Cross-Origin)

Frontend:
  - HTML5 + CSS3 + JavaScript
  - Supabase JS SDK (authentification)
  - Fetch API (appels HTTP)

Déploiement:
  - GitHub (version control)
  - Render (serveur)
  - Supabase (base de données cloud)

═══════════════════════════════════════════════════════════════

🚀 DÉMARRAGE RAPIDE:

Local:
  1. npm install
  2. cp .env.example .env
  3. Remplir .env avec clés Supabase
  4. npm start
  5. Ouvrir http://localhost:3000

Production (Render):
  1. GitHub: git push
  2. Render: Connecter repo
  3. Render: Ajouter env vars
  4. Render: Deploy
  5. Accès: https://cadexair-portal.onrender.com

📊 RÔLES & PERMISSIONS:

Admin:
  ✓ Créer utilisateurs
  ✓ Assigner bons de travail
  ✓ Voir tous les bons + statuts
  ✓ Voir tous les utilisateurs

Chef d'équipe:
  ✓ Voir ses bons assignés uniquement
  ✓ Mettre à jour statut (En attente → En cours → Complété)
  ✗ Ne peut pas voir bons d'autres chefs
  ✗ Ne peut pas créer utilisateurs
